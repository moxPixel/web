## 3. DMARC

### Objectif
Mettre en place un enregistrement DMARC pour améliorer la sécurité email et la réputation du domaine.

### 3.1 Prérequis

Avant de configurer DMARC, vous devez avoir :
- [ ] **SPF** (Sender Policy Framework) configuré
- [ ] **DKIM** (DomainKeys Identified Mail) configuré

### 3.2 Configuration DMARC

#### Étape 1: Vérifier SPF et DKIM

```bash
# Vérifier SPF
dig TXT unlock-formation.fr | grep spf

# Vérifier DKIM
dig TXT default._domainkey.unlock-formation.fr | grep dkim
```

#### Étape 2: Créer l'enregistrement DMARC

Ajoutez un enregistrement TXT DNS au nom de `_dmarc.unlock-formation.fr` :

```
v=DMARC1; p=none; rua=mailto:dmarc@unlock-formation.fr; ruf=mailto:dmarc@unlock-formation.fr; fo=1; sp=none; pct=100
```

**Explication des paramètres**:
- `v=DMARC1`: Version du protocole
- `p=none`: Politique initiale (monitoring uniquement, pas de rejet)
- `rua`: Adresse email pour les rapports agrégés
- `ruf`: Adresse email pour les rapports de failure
- `fo=1`: Rapport sur tous les échecs d'authentification
- `sp=none`: Politique pour les sous-domaines
- `pct=100`: Pourcentage d'emails à vérifier (100%)

#### Étape 3: Mode monitoring (recommandé pour débuter)

Pendant 2-4 semaines, gardez `p=none` pour analyser les rapports sans bloquer d'emails.

#### Étape 4: Passage en production

Après analyse des rapports, passer à `p=quarantine` puis `p=reject` :

```
v=DMARC1; p=quarantine; rua=mailto:dmarc@unlock-formation.fr; ruf=mailto:dmarc@unlock-formation.fr; fo=1; sp=quarantine; pct=100
```

### 3.3 Validation

#### Outils de validation
- [ ] **dmarcian.com**: Analyseur DMARC (gratuit)
- [ ] **MXToolbox**: Vérification DNS
- [ ] **Google Postmaster Tools**: Si vous utilisez Gmail/Google Workspace

#### Commandes de vérification

```bash
# Vérifier l'enregistrement DMARC
dig TXT _dmarc.unlock-formation.fr

# Vérifier avec curl
curl -s "https://dmarcian.com/dmarc-xml-validator/" | grep -i dmarc
```

### 3.4 Monitoring

- [ ] Configurer une **adresse email dédiée** pour recevoir les rapports DMARC
- [ ] Analyser les rapports **hebdomadaires**
- [ ] Identifier les sources légitimes non authentifiées
- [ ] Ajuster SPF/DKIM si nécessaire

## 4. HTTP/2

### Objectif
Activer et valider HTTP/2 pour améliorer les performances du site.

### 4.1 Vérification actuelle

#### Commande de test

```bash
# Vérifier si HTTP/2 est activé
curl -I --http2 https://www.unlock-formation.fr

# Vérifier avec verbose
curl -v --http2 https://www.unlock-formation.fr 2>&1 | grep -i "http/2"

# Alternative: utiliser http2check
curl -I --http2-prior-knowledge https://www.unlock-formation.fr
```

#### Via DevTools Chrome
1. Ouvrir Chrome DevTools (F12)
2. Onglet **Network**
3. Vérifier la colonne **Protocol** (doit afficher `h2`)

### 4.2 Configuration serveur

#### Nginx

```nginx
# Dans /etc/nginx/sites-available/unlock-formation.fr
server {
    listen 443 ssl http2;  # http2 activé
    listen [::]:443 ssl http2;
    
    server_name www.unlock-formation.fr unlock-formation.fr;
    
    # SSL configuration
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    # HTTP/2 optimizations
    http2_max_field_size 16k;
    http2_max_header_size 32k;
    
    # ... reste de la config
}
```

#### Apache

```apache
# Dans /etc/apache2/sites-available/unlock-formation.fr.conf
<VirtualHost *:443>
    ServerName www.unlock-formation.fr
    
    # Activer HTTP/2
    Protocols h2 http/1.1
    
    # SSL configuration
    SSLEngine on
    SSLCertificateFile /path/to/cert.pem
    SSLCertificateKeyFile /path/to/key.pem
    
    # ... reste de la config
</VirtualHost>
```

#### Vercel / Netlify
- HTTP/2 est **activé par défaut** sur ces plateformes
- Aucune configuration nécessaire

### 4.3 Validation post-déploiement

```bash
# Test 1: Vérifier le protocole
curl -I --http2 https://www.unlock-formation.fr | head -1
# Doit retourner: HTTP/2 200

# Test 2: Vérifier les headers
curl -I --http2 https://www.unlock-formation.fr | grep -i "http/2"

# Test 3: Utiliser online tools
# - https://tools.keycdn.com/http2-test
# - https://http2.pro/check
```
